Privacy policy

Last updated: September 2, 2026

This policy covers LevAssistant, a personal scheduling application, and these public information pages.

Data we access

With the account owner’s permission, LevAssistant reads Google Calendar events and calendar-list information. It uses calendar metadata to confirm the connected account and reads events from that account’s primary calendar for the current day.

Event responses can include titles, dates, times, descriptions, locations, identifiers, recurrence information, and other event metadata supplied by Google. LevAssistant displays the event’s title, time, location, and description. It does not request access to Gmail messages, contacts, or Google Drive files.

How we use the data

Calendar data is used to provide the household’s daily schedule. Access is read-only. LevAssistant does not create, edit, delete, or send invitations for calendar events.

Google Calendar data is not sold, used for advertising, sent to AI services, or used to train AI models. It is not published on these information pages.

LevAssistant’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and access

Google authorization tokens are stored in a file on the home appliance with access restricted to its operating-system account. Google credentials are not included in the source repository or the public website. The app does not receive the Google account password.

The app keeps a working copy of today’s displayed events in memory. It replaces that copy as the schedule refreshes and clears it when the app restarts. A temporary connection failure may leave the most recently loaded schedule visible with a stale-data notice.

Anyone able to use the household touchscreen or reach its web interface on the home network can view the displayed schedule. The appliance currently serves that interface over local HTTP. Its Google API connections use HTTPS.

Sharing and public website hosting

The appliance communicates directly with Google to retrieve calendar data. Calendar data is shown to household users and is not transferred to Cloudflare to host these pages.

Cloudflare hosts the public information site and may process visitors’ IP addresses and request information to deliver and protect it. These pages contain no added analytics scripts, advertising, forms, or application cookies. See Cloudflare’s privacy policy for its processing practices.

Disconnecting and deletion

The account owner can revoke LevAssistant’s access through Google Account connections. To remove the appliance’s authorization, its administrator can stop LevAssistant, delete its saved Google token file, and restart it. Restarting clears cached events; deleting the token prevents further calendar reads until the account is connected again.

These steps do not delete the source events in Google Calendar. Any administrator-created backups must be handled separately. For help disconnecting or removing local data, contact info@easlancapital.com.

Household use and changes

The connection is managed by a household adult. The app is not offered for public registration and does not create separate Google accounts for children. This policy will be updated when data practices change, before enabling new uses of Google data.
