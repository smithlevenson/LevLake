# Testing

**Status:** Living Document

**Last Updated:** 2026-08-01

**Audience:** Developers

---

# Purpose

Document how LevLake is verified before committing and deploying.

---

# Smoke Test

Verify:

- Application starts
- Home page loads
- CSS loads
- Images load
- No console errors
- No server errors

---

# UI

Verify:

- Mobile layout
- Desktop layout
- Typography
- Calendar
- Reservation cards
- Lake Brief

---

# Functional

Verify:

- Navigation
- Reservation workflow
- Calendar display
- Responsive layout

---

# Before Commit

- Run application
- Verify changed feature
- Remove debug code
- Review documentation
